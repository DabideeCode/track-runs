# Project context

You are building **Track**, a web app. The complete requirements are in `requirement.md` at the project root.

- `requirement.md` is the single source of truth. Do not edit, move or delete it.
- Use npm and the Node.js version in `.nvmrc`.
- Work only inside this project folder.
- Do not push to, add or change any git remote.
- If `requirement.md` does not cover a decision, make a reasonable choice and record it with your other planning documents.

## Tools available

These MCP servers are connected. Use them when they help.

- `context7`: up-to-date documentation for libraries and frameworks.
- `mobbin`: real-world UI and UX design references.
- `chrome-devtools`: open the running app in Chrome, take screenshots, read the console and record performance traces.
